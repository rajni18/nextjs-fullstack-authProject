Foundational Project: Authentication Flow with Next.js & TypeScript

📝 Overview
This project implements a complete authentication flow using Next.js, TypeScript, Tailwind CSS, MongoDB, and Mongoose.

🔑 Features
User Signup with email verification (via Mailtrap + Nodemailer)
Login with token handling
Profile page rendering
Logout functionality
Protected routes with middleware
API testing performed using Postman

⚙️ Tech Stack
Frontend: Next.js, TypeScript, Tailwind CSS
Backend: MongoDB, Mongoose
Email Service: Nodemailer + Mailtrap
Tools: Postman, Git/GitHub, Vercel

How to Run
# Clone the repository
git clone [<repo-url>](https://github.com/rajni18/nextjs-fullstack-authProject.git)
cd project-folder

# Install dependencies
npm install

# Run the project
npm run dev
